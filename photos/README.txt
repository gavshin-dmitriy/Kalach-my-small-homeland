ФОТОГРАФИИ
Кладите файлы прямо в эту папку (photos/). Называйте так:  ИМЯ-НОМЕР.jpg

  pechera-1.jpg   — главное (большое) фото Пещеры
  pechera-2.jpg   — дополнительные фото (галерея), -3, -4 ... и т.д.
  yakobin-1.jpg, komov-1.jpg, apteka-1.jpg, topilovka-1.jpg, muzey-1.jpg, muzey-2.jpg, muzey-3.jpg

ИМЯ — это id места из data.js (pechera, yakobin, komov, apteka, topilovka, muzey).
Подходят форматы jpg, jpeg, png, webp. Номера идут подряд без пропусков.
Список фото нигде прописывать не нужно — сайт находит их сам.

РАЗМЕР ФОТО (чтобы страница быстро открывалась на телефоне)
  • Длинная сторона 1600 px (например 1600x1200), горизонтальное фото 4:3 или 3:2.
  • Формат JPG, качество 75-80%.
  • Вес одного файла 200-500 КБ, не больше 1 МБ.
  Уменьшить удобно бесплатно онлайн: squoosh.app (выберите MozJPEG, качество 75-80, Resize 1600 px).
