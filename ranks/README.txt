КАРТИНКИ ЗВАНИЙ
Для каждого звания нужна своя картинка. Имя файла = id звания из data.js (RANKS):
  novichok.svg   — Новичок
  kraeved.svg    — Краевед
  znatok.svg     — Знаток Калача
Сейчас здесь стоят простые рисунки-заготовки. Чтобы поставить свои, загрузите в эту папку
файл с тем же именем и форматом png, jpg, jpeg или webp (например, znatok.png) — он
автоматически заменит заготовку (png/jpg/webp приоритетнее svg). Лучше квадратные, ~600x600 px.
