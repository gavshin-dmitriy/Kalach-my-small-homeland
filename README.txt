ФОТОГРАФИИ
Кладите файлы прямо в эту папку (photos/). Называйте так:  ИМЯ-НОМЕР.jpg

  pechera-1.jpg   — главное (большое) фото Пещеры, оно же кружок на карте
  pechera-2.jpg   — дополнительные фото (галерея), -3, -4 ... и т.д.
  yakobin-1.jpg, komov-1.jpg, apteka-1.jpg, topilovka-1.jpg

ИМЯ — это id места из data.js (pechera, yakobin, komov, apteka, topilovka).
Подходят форматы jpg, jpeg, png, webp. Номера идут подряд без пропусков.
Список фото нигде прописывать не нужно — сайт находит их сам.
Совет: размер файла лучше не больше 1 МБ, чтобы страница быстро открывалась на телефоне.
